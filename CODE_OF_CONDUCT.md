# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, focus on the work, and do not harass anyone.
Unacceptable behaviour can be reported privately to the maintainers via a GitHub security advisory or a direct
message on GitHub; reports are handled confidentially.
