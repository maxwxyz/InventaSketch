Set up InventaSketch

PowerPoint on Windows, on the Mac and on the web

Address of this add-in:

  1. Download the manifest (it already contains the address above).
  2. Open PowerPoint (Windows, Mac, or PowerPoint on the web in any browser, also on Linux) and open a presentation.
  3. Home > Add-ins > More Add-ins > My Add-ins > Upload My Add-in, choose the downloaded file.
  4. The "InventaSketch" tab appears; "Open editor" opens the task pane.

If the InventaSketch COM add-in is installed on Windows, PowerPoint hides this add-in; use the COM add-in there. If the local web add-in (InventaSketch-Web, server on your own computer) is installed, uninstall it first, otherwise both registrations compete. Presentation data is not sent to this server; it only serves the program files.

  1. Manifest herunterladen (es enthält bereits die Adresse oben).
  2. PowerPoint öffnen (Windows, Mac oder PowerPoint im Web in jedem Browser, auch unter Linux), eine Präsentation öffnen.
  3. Start > Add-Ins > Weitere Add-Ins > Meine Add-Ins > Mein Add-In hochladen, die heruntergeladene Datei wählen.
  4. Der Reiter "InventaSketch" erscheint; "Editor öffnen" öffnet den Aufgabenbereich.

Ist unter Windows das COM-Add-in von InventaSketch installiert, blendet PowerPoint dieses Add-in aus; dort das COM-Add-in verwenden. Ist das lokale Web-Add-in (InventaSketch-Web, Server auf dem eigenen Rechner) installiert, es zuerst deinstallieren, sonst konkurrieren beide Einträge. Präsentationsdaten werden nicht an diesen Server gesendet; er liefert nur die Programmdateien aus.

Without "Upload My Add-in"

  
If "Upload My Add-in" is missing (older version, not signed in to Microsoft 365) or the upload fails, PowerPoint
  also reads the manifest from a fixed folder. First download the manifest above (manifest.xml,
  saved to the "Downloads" folder).

  
Fehlt der Eintrag "Mein Add-In hochladen" (ältere Fassung, ohne Anmeldung bei Microsoft 365) oder
  klappt das Hochladen nicht, liest PowerPoint das Manifest auch aus einem festen Ordner. Zuerst oben das Manifest
  herunterladen (manifest.xml, landet im Ordner "Downloads").

Without PowerShell: put the manifest into a shared network folder; in PowerPoint File > Options > Trust Center >
    Trust Center Settings > Trusted Add-in Catalogs add the folder address (\\Computer\Share), tick "Show in Menu"
    and restart PowerPoint; then Home > Add-ins > More Add-ins > Shared Folder.

    
If your organization blocks add-ins by policy, these ways do not work either. Ask your IT to deploy
    InventaSketch centrally with this manifest (Microsoft 365 admin center > Integrated apps).

  

  

    
Ohne PowerShell: das Manifest in einen freigegebenen Netzwerkordner legen, in PowerPoint Datei > Optionen >
    Trust Center > Einstellungen für das Trust Center > Kataloge vertrauenswürdiger Add-Ins die Adresse des Ordners
    (\\Rechner\Freigabe) hinzufügen, "Im Menü anzeigen" ankreuzen, PowerPoint neu starten; danach
    Start > Add-Ins > Weitere Add-Ins > Freigegebener Ordner.

    
Hat die Organisation Add-ins per Richtlinie gesperrt, gelten diese Wege ebenfalls nicht. Dann die IT bitten,
    InventaSketch mit diesem Manifest zentral bereitzustellen (Microsoft 365 Admin Center > Integrierte Apps).
